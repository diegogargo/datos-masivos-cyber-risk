## Evidencia individual requerida

Cada integrante realizará:

- al menos dos commits relevantes;
- un pull request propio;
- una revisión de un pull request ajeno;
- participación en su issue asignada.

## Rotación de revisiones

- José Miguel revisará el pull request de Diego.
- Santiago Nicolás revisará el pull request de José Miguel.
- Diego revisará el pull request de Santiago Nicolás.

## Reglas de integración

- Ningún integrante realizará cambios directamente en `main`.
- Cada contribución se realizará desde una rama independiente.
- Los cambios se incorporarán mediante pull requests revisados.
- Cada pull request estará relacionado con su issue.
- Los resultados y pruebas deberán ser reales y reproducibles.
