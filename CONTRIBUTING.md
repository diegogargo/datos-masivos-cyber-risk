# Guia de contribucion

1. Elegir o recibir un issue.
2. Crear una rama desde `main` con el nombre acordado.
3. Hacer cambios verificables y commits claros desde la cuenta propia.
4. Ejecutar pruebas y notebooks relacionados.
5. Abrir un pull request que enlace el issue y describa la validacion.
6. Solicitar una revision real de otro integrante.
7. Integrar despues de atender la revision.

No incluir datasets grandes, rutas personales, credenciales, tokens ni API keys.
